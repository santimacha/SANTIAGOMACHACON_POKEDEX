# Creación de la cuenta de Azure pública (Microsoft Azure Students)

Este tutorial describe, paso a paso, cómo se creó la cuenta en la nube pública que se utilizó para desplegar la aplicación **PokeDex**: **Microsoft Azure**, a través de la oferta **Azure for Students**.

> El proceso de despliegue de la aplicación se documenta en [`Despliegue.md`](./Despliegue.md).

## 1. Requisitos

Para poder crear la cuenta es necesario contar con:

- Un correo electrónico educativo que sea válido.
- La verificación del estatus de estudiante.
- Un número de teléfono con el cual confirmar la cuenta.

![Requisitos](img/readme-00-requisitos.png)

## 2. Procedimiento paso a paso

### Paso 1. Entrar al portal de Azure for Students

Se abre el navegador y se accede a la página de la oferta: <https://azure.microsoft.com/free/students>

Esta oferta otorga un crédito de Azure de 100 USD, no exige tarjeta de crédito y además incluye servicios gratuitos.

![Paso 1 - Portal de Azure for Students](img/readme-01-pagina-oferta.png)

### Paso 2. Iniciar el registro

Se hace clic en el botón **Empezar gratis**.

![Paso 2 - Empezar gratis](img/readme-02-empezar-gratis.png)

### Paso 3. Acceder con la cuenta

Se inicia sesión utilizando el **correo electrónico educativo**:

1. Se escribe el correo institucional y se pulsa **Siguiente**.
2. En caso de que Microsoft avise que ese correo está asociado a más de una cuenta, se selecciona **Cuenta profesional o educativa**.
3. Se ingresa la contraseña de la institución y se pulsa **Iniciar sesión**.

![Paso 3 - Iniciar sesión](img/readme-03-iniciar-sesion.png)

### Paso 4. Comprobar el estatus de estudiante

Se llena el formulario de **Academic Verification** con los siguientes datos:

1. Nombre y apellido.
2. País.
3. Nombre de la institución educativa.
4. Fecha de nacimiento.
5. Correo electrónico de la institución (aparece ya completado).
6. Se resuelve el rompecabezas de verificación ("no soy un robot") y se pulsa **Next**.
7. Se pulsa **Verify academic status**.

Al finalizar, se muestra el mensaje **Verification complete!**.

![Paso 4 - Verificar estatus de estudiante](img/readme-04-verificar-estudiante.png)

### Paso 5. Confirmar la cuenta

La cuenta se confirma por medio de un número de teléfono. A continuación se muestra la pantalla **Confirming your account...**, mientras Azure termina de activarla.

![Paso 5 - Verificar la cuenta](img/readme-05-verificar-cuenta.png)

### Paso 6. Cuenta lista

La cuenta **Azure for Students** queda activa y el portal se abre en la sección **Education | Overview**, desde donde es posible consultar:

- El crédito disponible y los días que quedan.
- Los servicios gratuitos, entre ellos Azure App Service y Azure Blob Storage.
- Software gratuito y rutas de aprendizaje.
- Recursos de ayuda, la calculadora de precios y las preguntas frecuentes.

![Paso 6 - Cuenta lista](img/readme-06-cuenta-lista.png)
